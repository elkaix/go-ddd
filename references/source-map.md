## Teaching shortcuts and corrections

These observations come from static inspection of the linked source. The safer rules are independent engineering guidance added by this skill; they are not claims about the book's complete treatment or upstream fixes.

| Observed source behavior | Safer implementation rule |
| --- | --- |
| [`chapter4/calendar_repository.go:19–26`](https://github.com/PacktPublishing/Domain-Driven-Design-with-GoLang/blob/c1da720aee79d136924857191a9c5d2ab0a53517/chapter4/calendar_repository.go#L19-L26) defers closing a connection immediately before returning it inside the repository. | Give the composition root explicit resource ownership and shutdown; return a live connection or pool. |
| [`chapter4/calendar_factory.go:18–30`](https://github.com/PacktPublishing/Domain-Driven-Design-with-GoLang/blob/c1da720aee79d136924857191a9c5d2ab0a53517/chapter4/calendar_factory.go#L18-L30) ignores an invalid closing-time parse and compares a booking timestamp to the result. | Check parsing, build opening/closing instants on the business date in its timezone, and validate ordered ranges. |
| [`chapter4/domain_service_after.go:13–24`](https://github.com/PacktPublishing/Domain-Driven-Design-with-GoLang/blob/c1da720aee79d136924857191a9c5d2ab0a53517/chapter4/domain_service_after.go#L13-L24) appends and returns before checking capacity; an unavailable product also returns nil. | Enforce capacity before mutation and return an explicit rejection when no item is added. |

## Primary supporting sources

Use these for the added guidance; verify the target project's versions and provider contracts during implementation.

- [Go transactions](https://go.dev/doc/database/execute-transactions) — transaction scope, commit/rollback and consistent database access.
- [Go cancellation](https://go.dev/doc/database/cancel-operations) — propagate context cancellation and timeouts to database operations.
- [Go race detector](https://go.dev/doc/articles/race_detector) — detect races on executed concurrent paths; passing does not prove all paths are race-free.
- [Go fuzzing](https://go.dev/doc/tutorial/fuzz) — exercise input boundaries and invariant violations through fuzzing.
- [Go code review comments](https://go.dev/wiki/CodeReviewComments) — Go conventions for interfaces, errors, contexts and maintainable code.
- [Bounded contexts](https://martinfowler.com/bliki/BoundedContext.html) — make model boundaries and relationships explicit.
- [CQRS](https://martinfowler.com/bliki/CQRS.html) — assess the benefits and complexity of separating command and query models.
- [Transactional outbox](https://docs.aws.amazon.com/prescriptive-guidance/latest/cloud-design-patterns/transactional-outbox.html) — coordinate durable state and event publication; account for duplicate delivery.
- [Timeouts, retries, and jitter](https://aws.amazon.com/builders-library/timeouts-retries-and-backoff-with-jitter/) — choose bounded retry budgets, timeouts and jitter around safe operations.
- [Compensating transactions](https://learn.microsoft.com/en-us/azure/architecture/patterns/compensating-transaction) — design business-specific compensation, recovery and idempotency.
